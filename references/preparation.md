# 课程准备与文件管理

定位视频和课程资料，核对课程及章节。教材按目录、索引和课程内容找到相关章节，阅读相关文字与图表；扫描版需注意 OCR 的可靠性。参考资料用于理解课程和术语，老师是否说过某个内容仍以音频为准。

整理主题及对应时段的术语表。可参考视频画面辅助确定时间，代码演示和动画要核对画面变化。对英文专业名词，结合课件和代码确认拼写。

检查环境时，使用识别环境的 Python 执行 `scripts/check_environment.py --work-dir 已有目录 --model 本地模型目录 --course2md 可执行文件` 可查看工具、模型文件及可用空间；这只是盘点，不代表模型已完成实际识别。根据当前设备选择兼容方案，优先使用已经配置好的环境。

原视频、课件与最终讲义保存在课程目录；每课的音频、原始识别、校对记录和截图集中保存在便于辨认的工作目录。记录原文件与结果的位置，以及哪些文件是临时产物。

完成讲义并以无声方式检查文字、图片及原视频文件依赖后，主动清理本次明确生成且不再需要的临时产物，例如从视频提取的中间音频、已嵌入讲义的截图副本、重复导出文件。只清理确认属于本次任务的产物，处理符号链接时仅删除链接本身；如文件是否仍被引用或是否属于本次任务无法确定，则保留并说明。保留原视频、课件、最终讲义、原始识别、必要的校对记录、共享模型和运行环境。生成或验证未完成时保留续跑需要的文件。完成后简要说明清理了什么、保留了什么。
